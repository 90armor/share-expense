# src/lib

Shared, framework-free helpers. Pure TypeScript — no Next.js, React or Prisma imports. Tests live next to each file as `*.test.ts`. Check this index before writing a new helper.

- `currency.ts` — supported currency codes (`MMK`, `USD`, `KHR`), `CurrencyCode` type, exponent per currency, `isCurrencyCode` guard.
- `money.ts` — `Money` (bigint minor units + currency), `parseAmount`, `formatAmount` / `formatMoney` (no Intl), `addMoney`, `subtractMoney`, `sumMoney`, `negate`, `isZero`, `assertSameCurrency` (throws on mixed currencies).
- `split.ts` — `splitEqually(total, participantIds)` → `ParticipantShare[]` (`{ participantId, share: Money }`, sorted by id): equal split, the remainder goes 1 minor unit each to the lowest ids (string order); throws on an empty list, duplicate ids or a negative total. Also exports `byCodeUnit(a, b)` (plain code-unit string order, no locale).
- `balance.ts` — `computeNetBalances(expenses, settlements = [])` → `NetBalance[]` (`{ memberId, net: Money }`, sorted by id; one entry per id in an expense or settlement, net 0 included; a settlement is a `Transfer` that credits `fromId` and debits `toId`) and `computeTransfers(nets)` → `Transfer[]` (`{ fromId, toId, amount: Money }`, greedy order: biggest debtor pays biggest creditor, re-evaluated after each transfer, ties to the lowest id). Pure, bigint only; throws on mixed currencies, duplicate ids, nets not summing to 0, a negative settlement or a settlement to the same member.
- `appError.ts` — `AppError` plain object (`VALIDATION` | `NOT_FOUND` | `CONFLICT` | `UNEXPECTED`, message, optional field map) and `appError()`.
- `result.ts` — `Result<T>` (ok / fail) with `ok()` and `fail()`; server code returns these instead of throwing across boundaries.
- `limits.ts` — input limits (`MEMBER_NAME_MAX_LENGTH` 40, `GROUP_NAME_MAX_LENGTH` 60 (visible characters), `NAME_MAX_CODE_UNITS_PER_CHAR` (code-unit backstop), `DESCRIPTION_MAX_LENGTH`, `AMOUNT_MAX_MINOR_UNITS`, `PARTICIPANTS_MAX`) shared by server validation and client forms (`maxLength`, hints); zod-free so client components can import it.
- `validation.ts` — zod schemas (`nameSchema(maxLength)` (trimmed, counts graphemes), `idSchema` (UUID v4, strict), `currencyCodeSchema`, `moneyAmountSchema(currency)`, `positiveAmountSchema(currency)` (> 0 and ≤ `AMOUNT_MAX_MINOR_UNITS`; expense and settlement amounts)) and `parseWith(schema, input): Result<T>` with a field → message map.
- `formState.ts` — `FormState<F, V?>` (`{ error, values }`, serializable; `V` only for a multi-value field) and pure form helpers shared by features: `readFormFields(formData, fields)`, `readFormList(formData, field)` (checkboxes sharing a name → `string[]`), `toFormState(error, values)`, `fieldError(state, field)`, `formError(state, visibleFields)`.
- `cx.ts` — `cx(...parts)` joins class names, skipping `false` / `null` / `undefined` / empty strings.
